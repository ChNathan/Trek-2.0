# Trek-2.0
Project report and files for Oslo Met EPS project. We built a gait tracker for real time gait asymmetry over varying windows.

Included in this Repo Are:
- Trek EPS Report ( Which is covered in additional detail via this presentation https://docs.google.com/presentation/d/1eJzCRBbl3npr1pbE6kb9zn8NsA4ln3SlZraTO1EqVzs/edit?usp=sharing )
  - This report includes the project's purpose, progress, and future recommendations. We believe this project could be piloted in research studies with an additional project iteration.
- Firmware Code for Left and Right device, with and without SD Card
- User Interface Code
- Short user manual on setting up the device
- Autodesk Invetor CAD File for Case
- KiCad PCB Schematics, BOM, and additional design files


For any questions, comments, or concerns, please don't hestitate to contact us.
